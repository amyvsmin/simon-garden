## 定義

整合開發環境（IDE）是「寫程式用的軟體應用，提供編輯輔助與錯誤修正工具」。內含 GUI（圖形使用者介面），給開發者各種選項去自訂與建構自己的程式。是跑 [[python]] 的三種環境之一（另兩種是 [[notebook]] 與 [[cli]] 命令列）。

## 關鍵面向

- **編輯輔助與錯誤修正**：自動補全、語法高亮、即時錯誤提示
- **含 GUI**：圖形介面、可自訂與建構程式
- **附帶 debugger**：多數 IDE 內建 debugger（除錯器），可設中斷點（breakpoint）定位錯誤，是 [[debugging]] 的利器
- **與其他環境並列**：IDE、[[notebook]]、[[cli]] 都能寫並跑 Python，各有適用場景
- **代表工具**：VS Code、PyCharm 等（課程未指定特定工具）

## 應用場景

- Simon 工作場景：寫正式、要維護的可攜腳本（accounting、veeam）時，IDE 的補全與錯誤提示比 notebook 更適合；探索性分析才用 notebook
- 一般場景：軟體開發、專案型程式撰寫、除錯

## 相關概念

- [[notebook]]：另一種寫 Python 的環境、偏互動探索
- [[cli]]：命令列環境、最底層可控
- [[python]]：IDE 是與 Python 互動的環境之一
