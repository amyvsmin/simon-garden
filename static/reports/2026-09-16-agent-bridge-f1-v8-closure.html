3. 芙莉蓮改壞過什麼，怎麼發現

Simon 回報症狀 · WSL Claude／芙莉蓮 查根因
v7 邊界錯

把「稽核時要看」誤做成「執行時要鎖」。
v7 的 source_files 混入 7 份常態維護文件。commit 55bbda5d 只改了調度說明兩行，就讓原雜湊失效；下一個傳輸邊界會把它當成程式漂移並永久停橋。

怎麼抓到

先沿 activation gate 逐段追，再用一個位元組做反證。
程式碼查證顯示 runtime 只因 manifest 把文件列為 source 才會讀它們；暫存夾具中改文件仍綠、改程式立即紅，證明問題在封裝邊界，不在 Bridge 邏輯。

驗證插曲

Windows 最終驗證第一次被沙盒擋住暫存資料夾。
輸出是 PermissionError，不是 F1 測試失敗。確認殘留暫存夾為空後移除，改在允許的執行環境重跑並全綠；沒有把環境錯誤冒充產品缺陷或假裝第一次就通過。
